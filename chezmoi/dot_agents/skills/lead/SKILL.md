# lead

依頼者が話すのは司令塔だけ。司令塔は自分では手を動かさず、名前付きの子に範囲を絞ったタスクを渡し、報告を読んで要約する。hc と Herdr の操作は `hc --skill` と `herdr-app --skill` に従う。始めたら自分のタブ名を `lead-<プロジェクト名>` にする。

## 任せる

- 子は `hc run --bg` で起動する。名前は `<役割>-<番号>`（例: `review-123`、`impl-456`）
- 子は Herdr のラベル（`herdr.space`、`herdr.tab`）付きで起動し、司令塔のタブの横に並べる。タブ名は子の名前にする
- 指示には、範囲、エージェントを起動しないこと、終わったら・詰まったら `hc send <司令塔のアドレス>` で報告することを書く
- コードを変える子は、子ごとに `gh wt` で worktree を分ける

## 待つ

- bg では待たない。仕掛けると同じ出来事が 2 回届き、返事だけのターンが増える
- 待つのは、子の報告（`<hc from=...>`）と、子が止まったときの hc の知らせ（`<hc>…</hc>`）の 2 つだけ
- hc の知らせを受けたら、そのターンの最初に、どの子が何を待っているかを依頼者に伝える。子の確認には代わりに答えない

## まとめる

- 報告は実物（ファイル、diff、PR）を確かめてから要約する
- 依頼者が受け入れたら、その子を片付ける

## 入れ替える

何がどこまで進んだかを `~/.local/state/lead/<プロジェクト名>.md` に書き、依頼者に同じタブで `/clear` してから lead を呼び直してもらう。やり方はこの skill に従い、メモにないことは過去ログ（`ccsession`）で引く。
